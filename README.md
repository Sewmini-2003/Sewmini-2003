**Playwright · JavaScript · Node.js · Page Object Model · Manual & Automated Testing**

### ☕ TaskFlow — Spring Boot Full-Stack Learning Project

**Java · Spring Boot · Spring Data JPA · Hibernate · MySQL · HTML · CSS · JavaScript · Postman**

A learning project created to understand the fundamentals of **Java Spring Boot and full-stack application development**.

The application provides a simple task management system with a REST API supporting CRUD operations for creating, retrieving, updating, and deleting tasks.

The frontend communicates with the Spring Boot backend using the JavaScript **Fetch API**, while MySQL is used for database persistence.

The API endpoints were tested using Postman.

[View Repository →](https://github.com/Sewmini-2003/taskflow-springboot)

### 🚚 SwiftTrack — Distributed Logistics Middleware

**JavaScript · RabbitMQ · PostgreSQL · Docker Compose · Socket.IO · JWT · SOAP · TCP · REST**

A collaborative middleware architecture project demonstrating communication between multiple services in a distributed logistics system.

The system uses microservices, an API Gateway, asynchronous messaging with RabbitMQ, real-time communication using Socket.IO, and multiple communication protocols including REST, SOAP, and TCP.

It also demonstrates the **Saga Pattern** for coordinating distributed workflows.

[View Repository →](https://github.com/Sewmini-2003/swiftLogistic)
